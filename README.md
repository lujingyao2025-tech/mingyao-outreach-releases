## 功能截图

### 一、认识界面

数据看板 —— 今日发送、成功、回复、失败、邮箱与待发送一览，每 5 分钟自动刷新。

![数据看板](screenshots/01-dashboard.png)

报表中心 —— 按时间、邮箱、任务统计发送、失败与回复，可导出。

![报表中心](screenshots/02-reports.png)

### 二、配置邮箱

邮箱账号 —— 多邮箱接入、配额、冷却、代理与分组，按额度自动轮换。

![邮箱账号](screenshots/03-mailboxes.png)

邮箱工作台 —— 单邮箱视角，查看 SMTP / IMAP / 代理 / 额度 / 授权状态与客户对话。

![邮箱工作台](screenshots/04-mailbox-workbench.png)

添加邮箱 —— 使用 Gmail App Password 接入，不打开 Google 登录页。

![添加邮箱](screenshots/19-add-mailbox.png)

### 三、准备客户

客户资料 —— 字段管理、分组管理、批量操作、导入导出，分页支持 20 / 50 / 100。

![客户资料](screenshots/06-contacts.png)

导入客户 —— 支持 CSV / Excel 批量导入，可先下载模板。

![导入客户](screenshots/18-import-contacts.png)

### 四、撰写模板

邮件模板 —— 变量可插入到主题或正文的光标处，发送前自动转为 HTML。

![邮件模板](screenshots/07-templates.png)

客户预览 —— 选择一位真实联系人，用真实数据预览排版。

![客户预览](screenshots/17-template-preview.png)

### 五、发送任务

发送任务 —— 任务列表与状态筛选。

![发送任务](screenshots/08-campaigns.png)

向导第 1 步 · 选择收件人 —— 按当前启用字段筛选，也可逐个勾选，自动排除黑名单 / 已退订。

![向导第 1 步 选择收件人](screenshots/12-wizard-recipients.png)

向导第 2 步 · 邮箱与计划 —— 自动轮换或手动指定邮箱 / 分组，立即或定时发送。

![向导第 2 步 邮箱与计划](screenshots/13-wizard-mailboxes.png)

向导第 3 步 · 内容与附件 —— 选择模板，显示最终发件人及其来源。

![向导第 3 步 内容与附件](screenshots/14-wizard-content.png)

预览邮件 —— 按发件顺序逐封预览，所见即所发。

![预览邮件](screenshots/15-preview-email.png)

向导第 4 步 · 发送前校验 —— 收件人、邮箱、发件人、冷却四项检查与容量预估。

![向导第 4 步 发送前校验](screenshots/16-wizard-validation.png)

### 六、回复与跟进

回复中心 —— 客户回复进入统一队列，不漏掉任何一条回复。

![回复中心](screenshots/05-reply-center.png)

跟进任务 —— 只提醒、不自动发送，只筛「已发送、到时间且未回复」的客户。

![跟进任务](screenshots/09-followups.png)

人工复核 —— 结果不明的邮件进入复核，禁止系统自动重发。

![人工复核](screenshots/10-review.png)

### 七、设置与更新

系统设置 —— 发送规则、桌面通知、账号与登录，以及从 GitHub Releases 检查更新。

![系统设置](screenshots/11-settings.png)

## 功能简介

| 模块 | 说明 |
| --- | --- |
| 01 / SEND | 多邮箱轮巡与配额管理 |
| 02 / INBOX | IMAP 收信与回复中心 |
| 03 / FOLLOW | 模板变量与自动跟进 |
| 04 / REPORT | 任务、邮箱与结果统计 |

### 安全与专注

- **本地加密保存**：邮箱密码、App Password 与代理密码本地加密保存，减少敏感信息暴露。
- **账号数据隔离**：账号级数据隔离，切换账号时任务、回复和客户数据互不串联。
- **专注不被打扰**：桌面通知、隐私模式与免打扰，重要回复及时知道，日常工作保持专注。
