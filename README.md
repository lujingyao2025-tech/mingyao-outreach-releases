# 名路邮箱助手 · Minglu Mail Assistant

> 把发送、回复、跟进放在同一个工作台。
> 多邮箱轮巡发信，统一回复中心，自动跟进未回复客户。

**发送 · 收信 · 跟进 · 报表** —— 把分散的邮箱和客户动作串成一条完整工作流。

## 功能介绍

| 模块 | 说明 |
| --- | --- |
| 01 / SEND | 多邮箱轮巡与配额管理 |
| 02 / INBOX | IMAP 收信与回复中心 |
| 03 / FOLLOW | 模板变量与自动跟进 |
| 04 / REPORT | 任务、邮箱与结果统计 |

- **发送**：多邮箱轮巡发信、配额管理与冷却时间，避免单个邮箱过载。
- **收信**：IMAP 收信，统一回复中心，客户回复进入同一队列。
- **跟进**：模板变量与自动跟进，未回复客户自动加入跟进。
- **报表**：任务、邮箱与结果统计，一目了然。

### 安全与专注

- **本地加密保存**：邮箱密码、App Password 与代理密码本地加密保存，减少敏感信息暴露。
- **账号数据隔离**：账号级数据隔离，切换账号时任务、回复和客户数据互不串联。
- **专注不被打扰**：桌面通知、隐私模式与免打扰，重要回复及时知道，日常工作保持专注。
